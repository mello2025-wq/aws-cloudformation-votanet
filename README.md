# Laboratorio de AWS CloudFormation & Serverless

Repositorio de prácticas de Infraestructura como Código (IaC) con AWS CloudFormation y Linux.

## Contenido

* `templates/votanet_app.yaml`: Arquitectura Serverless completa (Amazon DynamoDB + AWS Lambda Python 3.12 + Amazon API Gateway + CORS).
* `templates/votanet_interfaz.html`: Interfaz web interactiva para registrar votos en tiempo real.
* `templates/mi_primera_instancia.yaml`: Despliegue de servidor EC2 t2.micro (Free Tier) en Amazon Linux 2023.
* `templates/tabla_dynamodb.yaml`: Tabla DynamoDB Serverless en modo bajo demanda (Pay-Per-Request).
